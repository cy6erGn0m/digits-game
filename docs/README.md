# API Reference

## Modules

## Game Levels

| Level | Range | Mode | Tasks |
|-------|-------|------|-------|
| easy-fixed | 1-5 | Same digit all tasks | 3 (no addToReach) |
| easy-random | 1-5 | Random each task | 3 (no addToReach) |
| medium-random | 1-10 | Random each task | 4 |
| hard-random | 1-20 | Random each task | 4 |
