# Техническое задание: «Изучаем цифры с Duolingo-подходом»
## (для детей 2–4 лет, с эмодзи и голосовыми подсказками)

## 1. Цели и аудитория
- Цель – в игровой форме научить ребёнка:
  - распознавать цифры от 1 до 5 (лёгкий уровень), 1–10 (средний), 1–20 (сложный);
  - соотносить количество предметов с цифрой;
  - использовать порядковый счёт (первый, второй, третий…);
  - постепенно справляться с отвлекающими факторами (цвет, тип предмета, наложение).
- Аудитория – дети 2–4 лет, не умеющие читать. Всё управление – касания, крупные элементы, голосовое сопровождение.

## 2. Основные принципы (для всех уровней)
- Никакого текста (кроме самих цифр). Все инструкции – голосом + крупная иконка громкоговорителя для повтора.
- Минимализм – чистый фон, никаких отвлекающих узоров на лёгком уровне.
- Мгновенная обратная связь:
  - Правильно → зелёная вспышка, звук «Молодец!», конфетти, автоматический переход через 1,5 секунды.
  - Ошибка → красная вспышка, мягкий звук «Попробуй ещё», варианты не блокируются (можно сразу нажать другой).
- Всегда 3 варианта ответа (даже на лёгком).
- Все эмодзи на лёгком уровне – одинаковые и одного цвета. На среднем и сложном добавляются отвлекающие факторы.

## 3. Модель данных (описание структур, без кода)

Основные сущности:

- Тип задания – один из четырёх:
  - countToDigit – «Сколько яблок?» → выбрать цифру.
  - digitToCount – «Покажи цифру 3» → выбрать картинку с 3 предметами.
  - addToReach – «Добавь 1, чтобы стало 3» (выбор +1/+2/+0).
  - ordinalPosition – «Выбери второе яблочко» (нажатие на объект в ряду).

- Задание содержит:
  - уникальный идентификатор,
  - тип задания,
  - загаданное число (1..20),
  - текст озвучки,
  - список предметов (эмодзи) – для типов countToDigit и ordinalPosition,
  - ровно три варианта ответа (каждый вариант – текст или набор эмодзи, флаг правильности),
  - уровень отвлечений (см. ниже).

- Предмет (эмодзи) может иметь:
  - сам эмодзи (например, 🐶),
  - цвет (опционально, для сложных заданий),
  - тип (например, «собака» для фильтрации).

- Уровень отвлечений описывается четырьмя флагами:
  - все ли эмодзи одинаковые,
  - все ли одного цвета,
  - требуется ли фильтровать по типу (считать только котиков),
  - пересекаются ли объекты (наложение).

## 4. Четыре типа заданий

### 4.1. Счёт → цифра (countToDigit)
- Показываем группу одинаковых эмодзи (или с отвлечениями).
- Вопрос: «Сколько [собачек]?»
- Варианты: 3 цифры (правильная, правильная+1, случайная из диапазона).
- Пример (лёгкий): 🐶🐶🐶 → варианты 2, 3, 5.

### 4.2. Цифра → счёт (digitToCount)
- Показываем крупную цифру 3.
- Вопрос: «Найди три яблока».
- Варианты: 3 картинки с разным количеством одинаковых эмодзи.
- Пример (лёгкий): 🍎🍎 , 🍎🍎🍎, 🍎🍎🍎🍎.

### 4.3. Добавь до числа (addToReach)
- Показываем N предметов + пустое место (или знак вопроса).
- Вопрос: «Сколько добавить, чтобы стало [target]?»
- Варианты: три кнопки +1, +2, +0 (всегда 3 варианта).
- Пример: 🐱🐱 + ? , target=3 → правильный +1.

### 4.4. Порядковый счёт (ordinalPosition)
- Показываем ряд из 5–10 одинаковых (или разных) эмодзи.
- Вопрос: «Нажми на [второе] яблочко».
- Вариантов ответа нет – ребёнок нажимает на один из объектов на экране.
- Для сложных версий: «Какой по счёту второй мячик?» (фильтрация по типу).

## 5. Уровни сложности (две независимые оси)

### Ось А – диапазон чисел

| Уровень   | Диапазон |
|-----------|----------|
| Лёгкий    | 1 – 5    |
| Средний   | 1 – 10   |
| Сложный   | 1 – 20   |

### Ось Б – отвлекающие факторы

| Фактор                     | Лёгкий         | Средний              | Сложный               |
|----------------------------|----------------|----------------------|-----------------------|
| Одинаковые эмодзи          | Да             | Нет (разные типы)    | Нет                   |
| Одинаковый цвет            | Да             | Нет (разные цвета)   | Нет                   |
| Фильтр по типу             | Нет            | Нет                  | Да (считать только котиков) |
| Пересечение / наложение    | Нет            | Нет                  | Да                    |

Итоговая сложность комбинируется: можно быть на «Средний диапазон + Лёгкие отвлечения» (числа до 10, но объекты одинаковые). Прогрессия задаётся динамически после успешного выполнения предыдущих комбинаций.

## 6. UI/UX требования

### 6.1. Экран задания
- Верхняя панель: персонаж-маскот, счётчик звёзд (за каждые 3 правильных ответа – звезда).
- Центральная область: вопрос (крупно, с иконкой громкоговорителя для повтора голоса).
- Ниже: контент (группа предметов / цифра / ряд) и 3 кнопки-варианта.
- Кнопки: крупные (не менее 100×100 pt), отступы, без текста – только цифра или набор эмодзи, или +1 и т.д.

### 6.2. Правила подсказок
- После двух ошибок подряд в одном задании – визуальная подсказка: подсветка правильного варианта на 2 секунды.
- Для заданий с отвлечениями (фильтр по типу/цвету) подсказка голосом: «Посчитай только красные яблочки», и на 1 секунду нужные объекты подсвечиваются зелёным, остальные становятся полупрозрачными.

## 7. Последовательность урока (на примере цифры 3, лёгкий уровень)
1. Экран-знакомство (необязательно): персонаж показывает цифру 3, произносит «Сегодня учим цифру три».
2. Задание 1 (Счёт→цифра): 🐶🐶🐶 → выбрать 3.
3. Задание 2 (Цифра→счёт): цифра 3 → выбрать 🍎🍎🍎.
4. Задание 3 (Добавь одного): 🐱🐱 + ? → выбрать +1.
5. Экран награды: звезда, похвала, переход к следующей цифре (или повторение, если были ошибки).

- После 3 правильных заданий подряд цифра считается выученной.

## 8. Технические упрощения для первой версии
- Drag&drop не используется: в задании «Добавь до числа» – три кнопки +1, +2, +0.
- Эмодзи берутся из системного шрифта – не нужно рисовать графику.
- Озвучка – синтез речи или заранее записанные фразы (минимальный набор: числа 1–20, «Молодец!», «Попробуй ещё»).
- Прогресс хранится локально (UserDefaults или файл).

## 10. Схема переходов между экранами
1. Заставка – начальный экран приложения.
2. Экран выбора уровня сложности – ребёнок или родитель выбирает: лёгкий / средний / сложный.
3. Экран выбора цифры – происходит автоматически на основе прогресса, начиная с цифры 1 текущего диапазона.
4. Цикл заданий на текущую цифру (3–4 задания подряд):
   - После правильного ответа → автоматический переход к следующему заданию (через 1.5 секунды).
   - После ошибки → повтор текущего задания. При повторной ошибке показывается подсказка (см. п. 6.2).
5. Экран награды – после успешного прохождения всех заданий на цифру:
   - показывается звезда, персонаж хвалит, звучат аплодисменты.
6. Проверка наличия следующей цифры в текущем диапазоне:
   - Если есть следующая цифра (например, после 1 идёт 2) → переход к п. 3 для новой цифры.
   - Если текущий диапазон полностью пройден (все цифры) → переход к выбору следующего диапазона (если доступен) или в главное меню.

Дополнительные переходы:
- В любой момент родитель может через отдельный раздел сбросить прогресс или вручную изменить уровень сложности.
- После полного прохождения всех уровней (1–20 с максимальными отвлечениями) приложение поздравляет и предлагает повторять пройденное.
