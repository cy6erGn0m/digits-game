# Изучаем цифры

> 🎮 **Играйте прямо сейчас: [cy6ergn0m.github.io/digits-game](https://cy6ergn0m.github.io/digits-game/)**

Образовательная игра для детей 2–4 лет, которая учит распознавать цифры от 1 до 20, считать предметы и использовать порядковые числительные. Выполнена в мобильном Duolingo-подобном формате с яркими emoji, голосовыми подсказками и системой звёздочек за достижения.

## Особенности

- **4 уровня сложности** — от простого (цифры 1–5) до сложного (1–20)
- **4 типа заданий** — счёт, сопоставление, сложение и порядковые числительные
- **Голосовые подсказки** — Web Speech API (русский язык)
- **Система звёзд** — награждение за правильные ответы и мастерство
- **Прогресс сохраняется** — в localStorage
- **Полностью на русском языке** — интерфейс, инструкции и голос

## Технологии

- Чистый HTML + CSS + JavaScript
- Без фреймворков и сборщиков
- CSS-анимации вместо canvas
- Простой Python-сервер для локального запуска

## Запуск локально

```bash
cd digits
python3 -m http.server 8080
```

Откройте `http://localhost:8080` в браузере (оптимизировано для мобильных устройств).
